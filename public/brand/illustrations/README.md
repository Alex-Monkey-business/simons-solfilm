# Illustrations

Standalone assets only. Nothing in the application currently imports these files.

- `optical-surface.png` — dark, reflective glass texture; intended as a full-bleed background detail.
- `film-layer.png` — material study of a smoked film layer over glass; intended for a service page or editorial block.
- `precision-trace.svg` — transparent line artwork for a dark surface; has a self-contained, motion-safe draw animation.
